# OpenFlux для Android

Полнофункциональный мобильный клиент OpenFlux для Android с поддержкой системного VPN (VpnService), локального SOCKS5-прокси, встроенного модуля удаленного деплоя нод на VDS/VPS и просмотра логов в реальном времени.

## Возможности

- **Системный VPN (`VpnService`)**: перехват и туннелирование всего сетевого трафика устройства через защищенный транспорт Яндекс.Документов (OnlyOffice WebSocket / HTTP relay).
- **Локальный SOCKS5-прокси**: запуск прокси-сервера на `127.0.0.1:1080` для приложений без необходимости перехвата всей системы.
- **Вставка ссылки на Яндекс.Документ**: автоматическая нормализация ссылок (удаление параметров, редиректов капчи и приведение к виду `https://docs.yandex.ru/edit/d/<ID>`).
- **Кнопка «Деплой»**: встроенный мастер развертывания выходных нод (Exit Node) на удаленных серверах Linux по SSH с автоматической установкой службы systemd и применением параметров в один клик.
- **Кнопка «Логи»**: просмотр логов сетевого ядра, VPN-интерфейса и процесса деплоя в реальном времени с возможностью быстрого копирования.
- **Минималистичный дизайн**: лаконичный интерфейс на Jetpack Compose и Material 3 («ничего лишнего»).
- **Сквозное шифрование**: AES-256-GCM с поддержкой быстрой генерации криптостойких ключей.

## Сборка проекта

### 1. Компиляция Go ядра (опционально, для gomobile)
В корне репозитория OpenFlux:
```bash
./build_android_aar.sh
```
Скрипт собирает `openflux/mobile` в `app/libs/mobile.aar`.

### 2. Сборка APK
```bash
# Проверка компиляции Kotlin:
.\gradlew.bat :app:compileDebugKotlin --console=plain -q

# Полная сборка debug APK:
.\gradlew.bat :app:assembleDebug
```
Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
